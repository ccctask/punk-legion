# runtime-robot Specification

## Purpose
规定游戏如何消费资产库冻结的履带机器人发布物，保证换装时各实例的头部、武器和动画状态独立，并允许客户端在本机资产库离线时加载所需资源。

## Requirements

### Requirement: 消费冻结履带机器人
游戏 SHALL 在本地加载与选定发布哈希一致的 GLB，并以米制大小展示单个选定头部与武器。

#### Scenario: 两台机体独立展示
- **WHEN** 一个场景使用默认外观，另一实例切至光带与钻头
- **THEN** 两台机体各自显示选定外观，移动与待机互不干扰

#### Scenario: 本机资产库关闭
- **WHEN** 独立运行机器人预览
- **THEN** 机器人、选定变体和动画通过游戏资源加载

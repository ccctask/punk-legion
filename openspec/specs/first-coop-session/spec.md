# first-coop-session Specification

## Purpose
通过两名新账号的一次真实合作，核对首次命名、换装、邀请、个人入账、可收工提示与自选维修的耗时和可达性。

## Requirements

### Requirement: First-day cooperative client evidence
The onboarding path SHALL support a new player earning daily completion from one real cooperative extraction, with a visible receipt and optional post-match repair.

#### Scenario: One cooperative victory
- **WHEN** two new players complete one invited cooperative run after naming and fitting the primary player’s robot
- **THEN** both obtain personal receipts for the same party and the base shows daily completion, with elapsed time and optional follow-up recorded separately

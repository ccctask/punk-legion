## 入口树与去向

私人基地是正常玩家起点。基地的“首玩与日常”存在单人/找队友捷径；这些不是新增玩法。场景打开后原基地/地图通常隐藏，子场景关闭后释放并重新读取原页；返回原页不等于结束服务器里的已登记场次。

```text
私人基地
├─ 出击 · 锈轨回收场 → 独行准备
│  ├─ 锈轨外围 · 快速回收
│  └─ 组队探索 · 寻找队友或邀请好友 → 锈轨合作大厅
├─ 封闭工厂 · 护送检修车 → 单人/一位好友护送准备
├─ 旧武器库 · 回收炮臂（南地开放后）→ 独行准备
├─ 公共区域图
│  ├─ 常驻组队探索图钉 → 锈轨合作大厅
│  ├─ 泵站遗迹图钉 → 单人PvE准备 / 好友合作准备
│  ├─ 黄铜转运场 / 线圈港 → 登记资格 / 营地指挥台
│  │  ├─ 实时进攻 / 接管防守 / 重连接回
│  │  ├─ 驻军及固定炮塔
│  │  ├─ 采集站建造报价
│  │  └─ 营地产出领取
│  └─ 秘宝图钉 → 单人/双人队伍 → 风险确认 → 候场 → 争夺/撤离
└─ 基地菜单→指挥官档案→好友与援军
   ├─ 好友申请/同意/拒绝/移除
   ├─ 参观基地
   ├─ 援军提议/接受/召回/入场指挥
   └─ 装配分享/查看缺件/存为自己的方案
```

代码入口：`game/base/base.gd:89` 至92及124、`game/base/base.tscn:112` 至124，`game/profile/profile.gd:43`，`game/world/world.gd:281` 至365。遇袭快捷入口由 `game/camp/defense_alerts.gd:69` 创建“地点名遇袭 · 回防”，私人基地和公共地图消费此入口；它跳到对应营地，不是私人基地的野生袭击系统。

## 玩家任务链

1. **锈轨独行与回收闭环。** 基地出击→读本人机况/入场报价→选机并满足12台/24点→确认出发→认证原场→移动/集火/选分支→近目标采集→突破首领→至少一台所选存活机体到出口4米内确认撤离→服务端核回收/战损→个人战报核实际入库与费用→回基地送修/装机。不能借用秘宝“全部存活机体到门”的条件。首胜钻头满仓则腾部件位→回同准备页领取；三胜配方进度与探索掉落是不同收益（`game/net/solo_mission.gd:154` 至168）。
2. **快速回收。** 本人先有锈轨胜利→独行准备展开外围回收→看UTC次数/普通能源与仓容报价→选一台完整待命机→确认扣1普通能源→取得唯一领取回执→回正常经营/手动出征；不进入战斗、不产生机体参战累计。未知结果用原回收请求核查。
3. **常规锈轨合作。** 日常/锈轨/世界合作入口→寻找队友或建队/输入邀请码→2–3人到大厅→各选本人的真实机并核全队共享12台/24点→各准备→队长全队出发→等全员到场（最多30秒）→各指挥己机，第一处协作门要求不同仍有效指挥官到节点→完成队伍共同撤离目标→仍在场成员按本人数据结算战报→原队再出发或本次收工→回基地。个人主动撤退可只退出本人；常规锈轨最终目标完成会结束全队本场，不能套用泵站/秘宝“各人自行撤离、队友继续”的规则。页面等待、真正排队、编队准备、战场集结必须区分（`game/net/party_mission.gd:133` 至164、185；继承 `game/net/solo_mission.gd:154` 至168）。
4. **工厂护送与南地。** 本人锈轨胜利开东地→基地工厂→选择独行/好友同行→选机/准备/费用确认→到场集结→车旁伴行并清轨道拦截→过检查点→护送到厂门→各人战果；本人首胜开放南侧30格、可回基地继续建造，当日结构材料按实际仓容结算。未解锁给前置说明，不把隐藏按钮当唯一引导。
5. **旧武器库。** 工厂开南地→基地旧武器库→选机出发→选择正面清守卫或绕侧闸断电→靠箱回收→携箱到门确认撤离→首胜烟囱炮臂/当日零件实际入库→机库装配；满仓保留首胜炮臂，腾位后回准备页领。撤退会放弃本线战利品，不能复用锈轨“已采物资可带走”说明。
6. **限时泵站PvE。** 世界泵站图钉→读窗口/本人费用/日收益/首通维修臂→选择单人或好友合作→建队选机准备→窗口内发起→集结→清守卫校准两阀→开共用箱→每人各自带机体到门确认撤离→个人回执→回世界地图/基地修理装机。活动关闭阻新开，已开场仍能恢复原进度。
7. **营地攻占。** 公共地图选择黄铜或线圈→核资源/开放/风险/现归属→登记当期资格→对应营地指挥台→选本方可用机，核与援军合计12/24及进攻能源→投入/入场→实时占核心16秒（守方对抗）→权威胜负/归属版本及真实战损→回对应地图营地详情。重连不重新付已付本场能源。
8. **营地经营与回防。** 自有营地图钉→指挥台查看库存/守军→勾机及可固定炮臂→保存驻军；可另开采集站报价→核私仓费用/产率/失守后果→确认建造；产出达到可领取额→核私人余位/保留量→领取回执。遇袭提示→接管本地防守→本场结算→重新核归属再经营。失守不能仍显示“领取/建造”成功。
9. **好友援助。** 档案好友页输入账号→对方同意→受援者如协攻先登记目标营地资格→机主选待命机/营地/攻防用途并提议→受援者接受→机体被援军预留→开战时机主从援助记录入场指挥己机→同场结束/战后召回→原机归还及个人战损→机主送修；协防实参受损在本次报价看抵扣，而不是材料奖励入库。
10. **装配分享。** 选双向好友和本人有效方案→分享→接收者选收到方案看底盘/插槽/版本及本人缺件→保存到本人方案栏→转本人机库制造/实装。分享定义不授予实体部件，也不代付方案栏权益。
11. **秘宝。** 世界秘宝图钉→读限时/货物损失/奖励与日资格→留空单人或写一名好友→各选个人合法机体→创建本次队→双人各提交名单、互看阵容、各确认同一轮风险→服务端共同预留→候场匹配→指挥己机争抢→临时包查看/满包选择换下物→回己方门→全部本人存活机体到门后确认撤离→货物、参与奖、稀有实物分别核真实入库→回图/基地维修。本人撤离不要求好友同时撤离；未撤离失能/超时丢临时货物，既有零件与身份保留。

## UI交接时不能丢的现状差异

- **入口重复但同一功能：** 基地日常、锈轨模式切换、世界常驻合作图钉最终都可到锈轨合作大厅。UI团队应识别它们的语义与回流，不按三个按钮画成三种玩法。
- **同一控件名不等于同一玩家动作：** 秘宝 `%Repair` 实际是“回到撤离点”，`%Retreat` 实际是“确认撤离”；工厂继承的 `%Alt` 是检查点/厂门，泵站则切双阀，武器库则切侧闸。交接应按玩家动作标识，不能照Node名生成新图标。
- **原生下拉/复选是现状，不是视觉规范：** 工厂模式、快速回收机体、好友援军用途与营地、秘宝换下货物当前均为下拉；出战机体是动态勾选列表。此盘点保留它们承担的选择状态和确认语义，不要求正式UI维持原生形态。
- **战报与生涯分开：** 探索本场回执展示资源账与机体本场击杀/施修；档案的累计参战/击败/维修由另一条机体档案线承接。旧solo文档“时间线/翻页”已经不是当前实际控件，不能作为待设计功能。
- **正常玩法与研发入口分开：** 当前玩家线不需要IP/UDP/协议版本/席位secret/测试业务号作为主内容。世界页“日程v/UTC”、营地回执短号等技术信息原型里可见，但不是创建新管理功能的依据。`game/*/tests`、`net/probe` 和运营脚本不是玩家面板。
- **试车台联机演习的归类待主代理统一。** 当前 `game/client/range.gd:145` 有“双人演习·准备”与房间联机，入口在基地菜单的试车台及档案的相关入口；它不同于上述探索/营地/秘宝。作为既有原型/研发路径需另列，不应无产品定案直接升格成首页又一种PvP。
- **真实持久状态要有独立反馈：** 选择草案、已准备、待队友确认、服务器预留、战场认证、集结、开战、个人撤退/撤离、终局核账、奖励已入库、结果未知应分开。尤其秘宝名单更改会撤销共同确认，营地费用与驻军保存不能混为一次本地勾选成功。
- **证据边界：** 此次没跑新手机流程/性能或截图。1083手机当前基地和HTTP已签，不证明本文所有面板的手机布局和触控已通过；UI设计交付后仍需另选真实流程验收，不以本盘点替代。

### UI不能承诺的当前缺口

1. 当前没有适用所有玩法的“暂停并安全退出”能力，不能先画成所有联机都暂停；必须区别临时断线、返上页、主动撤退、成功撤离、离队和收工。
2. 当前多个玩法的结算呈现不同：探索有完整个人战报，营地是终局简报，秘宝是货物/参与奖/打捞文本结果；统一视觉可以规划，但不能把不存在的数据字段当作后端已经能交付。
3. 当前没有在所有费用/货物有损动作上统一的二次确认弹窗；秘宝有明确阵容风险确认，工厂/独行依出发报价，营地建造独立报价。为正式UI新增确认状态属于后续交互落地任务，不能在现状列宣称已有。
4. 各线异常反馈多为原型文本、禁用与手动读取，尚不能承诺通用网络遮罩、完整可访问性、所有手机安全区/手势冲突已解决；本轮只读盘点不会补验这些。
5. 泵站按钮虽叫“好友合作”，当前服务端加入/出发并不执行工厂那样的双向好友校验；实际是可分享邀请码的2至3人合作。工厂与秘宝双人有好友资格要求。正式交接需准确表达当前资格，不在现状稿补一个不存在的互好友门槛（`server/party.py:220` 至225、260至262）。
6. 不能把所有撤离做成同一条件：锈轨独行/常规合作目标采集只需所选合法存活机中至少一台到4米内，常规合作完成最终出口会结束全队本场；泵站各指挥官可独立近门撤离；秘宝要求本人的全部存活机体到2.2米内。应共享视觉结构、保留各玩法权威条件差异。

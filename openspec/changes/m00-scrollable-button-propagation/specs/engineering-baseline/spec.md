# Spec Delta

## ADDED Requirements

### Requirement: 主干滚动控件的拖动与点击隔离
已评审的私人基地常用操作、新手引导与合作大厅普通释放触发按钮及机器人选项 SHALL 在有滚动余量时允许从控件发起的触摸拖动传递给所属滚动区域；拖动不得提交按钮行为或切换选机，普通短点击应仅触发该目标一次。控件集合和平台证据 SHALL 明确登记，不能以桌面机制对照替代安卓整合验收。

#### Scenario: 从基地引导按钮向上滚动
- **WHEN** 基地右侧区域有可滚动余量且玩家从已评审的引导按钮发起向上拖动
- **THEN** 内容向上滚动，公共区域入口可按正常布局到达，拖动不打开该按钮关联的场景或发出业务意图

#### Scenario: 合作大厅选机与滚动
- **WHEN** 玩家在合作大厅的机器人选项上发起拖动，随后对一个可见选项作普通短点击
- **THEN** 拖动只滚动内容且保持选机，短点击只切换所点机器人一次，其他机器人保持原选择

#### Scenario: 普通按钮保持现有提交边界
- **WHEN** 玩家短点击一个已评审的正常操作按钮
- **THEN** 控件只发出一次原有意图，禁用、读取门和现有请求确认规则继续生效，拖动传播不绕过业务权限或将界面事件当成权威成功

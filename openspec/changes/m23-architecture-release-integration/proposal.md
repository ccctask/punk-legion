# Proposal

## Why

G1–G3的源码整改已获限定验收，但1077客户端和当前r2服务尚未包含它们。实际发行还存在profile镜像缺少新维护模块COPY、旧net/probe联测资源进入APK的缺口；必须把已签源码、完整候选和真实验证连成可交付版本。

## What Changes

- 复用既有冻结/签名/构建流程，审完整工作树相对rc1077及实际r2的差异，纳入已签11文件及本次必要发布适配，分别绑定客户端和服务来源。
- 最小补profile Dockerfile的模块打包；仅Android Release排除旧net/probe场景和脚本，保留玩家诊断/版本菜单及正常网络依赖。
- 最终源锁和版号签发等M06性能修订范围确定后再进行，避免反复构建。随后独立检查实际APK/PCK内容、实际镜像依赖及新数据玩家链，不把源码或过滤配置冒充发行证明。
- 候选功能与模拟器性能通过后，使用稳定操作目录交接新试玩，核实际使用方/活场/在途后精准退役；无旧库迁移。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无新增玩法或规格行为；本项整合既有已签修复及内部打包/交付适配，skip_specs=true。原历史迁移场景不构成本轮执行要求，按AGENTS默认新数据规则。

## Impact

主责M23；关联M01导出、M07维护、M04动作、M14/M15探索、M24大厅、M22运行交接。源依据见[任务卡](../../../build/architecture-review/g4-release-task-input.md)及[G4输入](../../../build/architecture-review/g4-delivery-input.md)。源码、构建、签发、测试与部署分别以design链接的实际根门为准；当前已签1078产物出口，不据此批准运行或接管。为同字节APK隔离验收，补准备已评审的独立AOSP测试映像及工厂data/全新AVD路径工具，不改客户端端点、签名或业务规则。当前1077/r2保持；不新增地图/部件、渠道、真实支付、资产重做或测试框架。真机/声音终验按[负责人安排](../../../AGENTS.md#负责人终验安排)交付完整可玩版后执行。

## Why
An owner can command the garrison, but must already know which public camp to inspect. The default fifteen-second map refresh is close to the sixteen-second core capture period.

## What Changes
Show an in-game alert on the owner's normal private-base and public-map screens, naming each owned camp under live attack and opening the existing defense console.

## Capabilities
### Modified Capabilities
- live-camp-contest

## Impact
M19 camp presentation, M17 base and map navigation, bounded foreground status reads.

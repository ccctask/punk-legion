## Context

已核server c88：少量路由提前返回；其余先在一个`BEGIN IMMEDIATE`中按顺序推进八域并提交，再登录或进入第二业务事务。第二事务持认证、`onboarding.capture`前后调用及业务动作，`authorized`中的本账号`raids.advance(active=True)`位置也有含义。前段提交不会被后段拒绝回滚。三个请求的真实闭包见[切片调查](../../../../build/architecture-review/a03-g2-slice-input.md)。

inventory.apply_stock按旧仓容推进生产后才变库存、再更新生产；production→raids→inventory有真实重入，raids先更新clock才调用库存钩子。当前证据不支持改顺序或直接按owner/route过滤。现有领域函数与SQLite事务机制继续复用。

## Goals / Non-Goals

目标是给全域请求维护一个应用层所有者、受限入口及可复验的提交/异常合同。纯内部守恒重构，跳过spec增量，不改变生效规格。关闭条件是实际改动符合该合同并通过独立选集；不能据此关闭A03扫描/锁成本及A10领域环。

不改维护时效、owner筛选、全局调度、鉴权、SQL/表、费用/奖励、spool或当前部署；不为本切片引入Godot场景、Autoload、生产HTTP接口或后台常驻服务。独立验证可运行真实loopback Handler工装。

## Decisions

### 应用入口与依赖

拟增加`services/profile/profile_maintenance.py`，公开唯一`advance_request_state(db)`，由`server.handle`原维护事务位置调用。该模块只按当前顺序调用`service_record.expire → recovery.complete_due → party.expire → expedition.expire → camp.expire → friends.expire → treasure.expire → raids.due_accounts`，不复制领域裁定或提供随意跳过步骤的参数。它可依赖八个领域模块，领域不得反向导入此应用入口；不导入server、不开连接、不提交/回滚、不持缓存/全局可变状态、不发网络请求。

server仍拥有连接及两个事务生命周期、鉴权、路由与capture位置。各领域仍拥有任务/机况/库存/战果等状态及其不变量；库存和收据仍在既有同事务入口写入。新模块是当前真实的跨域用例组合，采用静态调用而非注册器/事件总线，顺序可直接审查。原地加注释不足以限制新增路由复制序列；通用调度器或Repository则扩大了尚未核明的事务和推进责任。

### 失败、未知结果与例外

维护入口不捕获或改写异常。维护中任一步向外传播异常，由原事务回滚已发生的前段写入，原Handler错误语义保留，业务不得继续；领域内部既有SAVEPOINT回滚及fallback仍由该领域裁定，例如camp.try_spooled_settlement/expire的坏spool回退，不能改成所有内部拒绝均中断整笔维护。维护成功后动作拒绝仍保前段已提交维护，动作事务不得留下部分扣费/占用/收据。未知HTTP结果继续由既有业务键处理，本切片不新增重试。

保持现有提前入口：账号恢复的独立限频/凭据事务，秘宝内部授权事务，compat早返，edit-status/defense-alerts/radar只读快照；普通注册/登录经过维护的现状也不改。只读前缀的method拒绝顺序不挪。这里只登记真实例外，不将所有路由折进通用事务包装。

### 实现范围和验收

生产允许两文件：server.py仅添加应用模块引用、以单调用替代原八行序列及必要合同注释；新profile_maintenance.py仅上述薄编排。其他生产函数和全部领域源、场景/资产及11项当前交付保护保持。实现差异增加参数、状态、跨域入口或改事务位置时必须退根审，不凭测试绿灯越界。

开发代理给精确diff、冻结源与必要自测；test_lead独立验五类判别场景：本轮到期维修已提交但非法出征拒绝；真实维护前段写入后受控后段异常导致整笔回滚；合法出征及重复业务键只产生一次费用/占用/entry；真实生产—野袭—库存重入只结算一次；一个真实只读例外不触发维护。另用观察包装调用真实函数核八项顺序，不能只mock顺序代替账务证据。精确夹具/错误注入、源锁与预算由test_lead提交后根审，不机械重跑八域×所有接口。

数据从独立不存在文件初始化为当前schema，正常新号/合法装配；需要时间进度时用明示的当前生成器，经真实校验且保字段白名单，不写假任务/回执。旧规格的升级场景不执行。无本切片UI/模型/网络协议改动，不为它启动安卓或Godot；默认一个临时Python工装、仅必要loopback HTTP/新库，精确预算准入再定，原失败/资源终态保留。源码候选通过不能重签1077/r2，整合发行另门。

## Risks / Trade-offs

- 全库维护仍有无关账号工作量及写锁 → 保留A03未解决出口，未来需owner/组队双方/援军完整闭包、无人请求推进责任和arrival时效评审后再缩域。
- 库存/生产/袭击领域环仍存在 → M08/M12/M16共同维护有限例外；保clock先写、旧仓容和设施损坏区间顺序，触及它们即复审，本案不删反向import。
- 薄模块可能只是搬文件 → 验收同时检查唯一应用入口、无反向依赖/私自事务及真实失败合同；未取得这些证据不得称G2切片通过。
- 提案时A01正式ENet仍未过 → 只准规划；G1完成且生产源重锁、test_lead预选就绪，主代理在本页追加最终结论后才派开发。该前置不是要求负责人重复授权。

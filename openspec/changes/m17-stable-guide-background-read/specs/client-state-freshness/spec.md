## ADDED Requirements

### Requirement: 已加载引导后台读取保持内容布局

客户端 SHALL 在Guide已有有效内容的后台读取期间保留原指引和今日目标文案，不因临时loading占位改变其布局；初载、真实内容变化和实际失败仍显示对应反馈。请求期间仍遵守原动作禁用及单槽合并规则。

#### Scenario: 相同数据的后台读取
- **WHEN** 玩家已滚动基地面板，已有Guide内容发起后台读取并收到相同权威内容
- **THEN** 在途和成功后原指引/目标文案及由其决定的布局保持稳定，请求期间动作按钮禁用，成功后恢复。

#### Scenario: 初载与读取失败
- **WHEN** Guide尚未加载或真实请求失败
- **THEN** 初载仍显示读取反馈，失败仍显示原恢复反馈，不伪称数据已更新。

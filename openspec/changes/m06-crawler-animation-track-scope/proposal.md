# Proposal

2026-11-15结果：研究已完成，候选收益门未达并精确撤销，原b0f包装器恢复；见[最终撤销签收](verification/root-withdrawal-review.md)。以下保留提案原意，不代表候选仍获发行许可或M06帧预算通过。

## Why

当前正常泵站原生CPU切片的76个Node3D变换传播leaf均有AnimationMixer调用祖先，原帧P95仍超预算。冻结履带GLB的Attack同时动画化气炮和钻头专属隐藏支路，现包装器只切可见性；需要先核真实导入轨道，再决定能否减少无可见贡献的更新。

## What Changes

- 第一阶段只读取真实导入Attack轨道与其目标/共享关系，确认可安全识别隐藏武器专属子树。
- 经主代理第二门后，候选实现只在履带视觉包装器按装配配置停用已确认隐藏专属Attack轨道，保证每实例动画资源隔离、共享父轨道/时钟/动作及底盘切换不变。
- 若导入轨道不匹配、可见挂件依赖该轨道或可用收益证据不足，停止该候选并记录，不扩大抽象或盲改模型。
- 独立验证视觉合同与同场景性能；未达帧预算不能宣布M06或完整版本通过。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。保留runtime-robot的独立展示和冻结资产合同及device-battle-baseline预算；仅内部视觉更新优化，skip_specs=true，不新增玩法或放宽验收。

## Impact

主责M06，关联M02视觉组合与M03装配选择，M04模拟/指令和M14/G3宿主不变。依据[真实归因根签](../m06-current-release-native-profile/verification/root-normal-a8-analysis-result-review.md)及[源码输入](../m06-current-release-native-profile/verification/native-hotspot-source-input.md)。候选生产源只限game/assets/steam_crawler/robot.gd，实际路径核前不改；不改GLB、协议、奖励、数据库或正式1077/r2。主代理评审，原开发代理实现与必要自测，test_lead独立正式验收及资源收尾，进度代理原页同步。

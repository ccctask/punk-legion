## Why

负责人已连接并授权实体 Android 手机，希望安装当前完整可玩内测版。1082 仅配置模拟器宿主 10.0.2.2，R2 服务仅绑定回环，直接安装无法联机。

## What Changes

- M23：复用已验收客户端快照、签名及服务镜像，产出独立局域网端点安装包，通过指定 USB 设备安装。
- M01 关联：构建工具接收明确 IPv4 端点，默认仍为模拟器地址；不修改运行时配置优先级或玩法。
- 持久操作目录增加指定 WLAN IP 的服务发布配置，保留原回环入口；核实实际服务使用后同版本重建。
- 记录包、构建工具、服务实例及安装结果。实体性能与听感仍由负责人终验。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `android-private-beta`: 交付可追溯的实体手机局域网安装包与 USB 安装记录。
- `runtime-environments`: 构建时显式选择内测 IPv4 服务宿主。

## Impact

只涉及 M23 构建、部署、交接和 M01 配置生成。当前客户端快照2345b028、后端镜像及业务协议不变。不迁移数据，不卸载或清空手机，不增加玩法、支付渠道或性能矩阵。

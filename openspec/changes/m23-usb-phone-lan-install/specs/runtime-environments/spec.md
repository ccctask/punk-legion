## ADDED Requirements

### Requirement: 内测构建显式配置IPv4宿主
构建工具 SHALL 将经验证的显式IPv4宿主一致写入内测端点配置与交接元数据，省略参数时保留模拟器默认地址。

#### Scenario: 局域网构建
- **WHEN** 使用合法局域网IPv4宿主构建内测APK
- **THEN** 所有既有服务端点使用该宿主且端口维持冻结配置，服务部署保留既有回环入口并提供声明的局域网入口。

#### Scenario: 无效宿主
- **WHEN** 构建参数含无效IPv4或配置注入字符
- **THEN** 构建拒绝该参数且不签发安装包。

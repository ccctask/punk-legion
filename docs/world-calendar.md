# 公开地图与服务端日程

适用于 M18 地图配置、运营更新与 M19 占领战接入。状态为生效，维护角色为档案服务及实时房间负责人。已验证 Godot 4.6.1、SQLite 档案 v10–v15。

私人基地的「公开地图」可进入锈轨回收场组队大厅，或查看黄铜转运场与线圈港的归属、争夺风险及服务端时窗。地图显示本地时间，准入以服务器 UTC 判定。当前时段和区域数量属于开发配置。

签名 1011 的地图把登记、查看资格和指挥台放在详情栏底部。两种横屏尺寸均可直接点选，详细日程与回执可上下滑动。切换营地后，迟到的登记或资格查询反馈归回原营地。

开发版中，自有公开营地遇袭时，私人基地和公共地图会出现带营地名的回防按钮。两处同时遇袭可分别点选。进入指挥台后点「接管防守」即可向驻军发令，离开编辑或回到前台会按当前战况刷新。仅在游戏内提示。[两地回防主验](../openspec/changes/archive/2026-11-09-m19-owner-camp-defense-alert/verification/root-review.md)

## 营主工坊名片

登录后从私人基地进入公开地图，点选有营主的黄铜转运场或线圈港，再点「查看营主工坊名片」。访客与营主本人能看到相同的营主名、当前持有的营地及各自产物。返回营地详情会保留地图选点。地图刷新后，易主的名片改为新营主；失去归属则回到中立营地详情。

私人基地的铭牌陈列默认只在原有范围可见。营主可在铭牌页点「向公开地图访客展示刻名」，所有已登录的地图访客即可看到当前铭牌上的机体刻名。再次点击可撤下。更换基地展品会清除公开选择，新展品需要单独确认。

## 修改日程

编辑 [calendar.json](../services/profile/config/calendar.json)。节点 ID 用于关联已有营地归属，更新名称或日程时保留原 ID。地图坐标为 0–1。每日时段以 UTC 当天零点起算的秒数表示。每组三项依次为开放、停止接受新场次、关闭。例如 `[85800,87000,87600]` 表示 UTC 23:50 开放，次日 00:10 停止新场，00:20 关闭。相邻或跨日时段不得重叠。

```powershell
docker compose exec -T profile python world_calendar.py --db /data/player.sqlite
```

配置挂载在档案服务。执行命令会立即校验并返回生效版本；地图请求也会检查挂载文件。相同内容沿用原版本，不合法的修改会使命令失败并说明原因；服务继续使用库中最近的有效版本。首次启动且无有效配置时，地图请求返回 503。客户端每 15 秒及回到前台时刷新。

## 入场与对账

玩家登记时使用 `POST /v1/world/admit` 提交稳定的请求键和节点 ID。服务保存账号、营地、冻结版本、起止时间与结算宽限期；重复请求取回同一收据。登记和实际创建占领战分两步。M19 在创建对局的事务中调用 `bind_battle(db,owner,grant_id,battle_id)`，冻结截止或最新日程已关闭新场时不能创建。恢复原场次时用相同 battle ID。

房间送达终局时，调用 `settlement_qualification(db,owner,grant_id,battle_id,finished_at)` 核验可信房间提交的结束时刻。越过宽限期才送达的结果，仍按冻结版本校验实际完赛时间。占领战模块负责在同一事务中按唯一场次处理战损、收益及 `set_owner`。

## 复测

从仓库根运行 `python -B services/profile/check_world.py --godot <Godot命令行路径> --captures <证据目录>`。脚本在临时数据库内模拟跨午夜、关闭和迟到终局，测试 v7、v8、v9 旧版迁移，并以两个独立客户端检查组队及争夺入口。本地正式玩家库无需改时钟。
SQLite 档案 v13 起，同一开放时段内，上一场结束后可用新意图键登记下一场。旧请求键、旧资格与其作战结果仍然可恢复。见[营地攻防与收益](camp-contest.md)。

## 营地参战能力

日程节点的 `contest_available` 由服务器发布。黄铜转运场、线圈港均可登记资格与进入相应指挥台。服务端日后若公布仅供预览的营地，地图收起该节点的登记和指挥按钮。对预览节点新发的入场请求返回 HTTP 409 `camp_preview_only`。历史请求仍按原业务键读取原回执。日程调整与战场接入分别维护，新增营地战场时同步更新该能力和地图回归。

## 雾钟泵房合作遗迹

从 1042 签名内测版起，个人首次参战并成功撤离泵房会回收一件带编号的战地维修臂。单人与合作共用每个账号一次的资格，已有其他来源的维修臂也可回收这一件。出发页将首通装备和按日结算的通用零件分开显示。个人战报记录这次结算时的装备编号或满仓留存情况，之后可从泵房准备页复看。

满仓时回到基地机库，先把一件闲置部件装上机体，腾出一个背包格后点「领取泵房维修臂」。泵房关闭后依然可领。领取中断时点「核对本次领取」，会沿用原操作编号。收到后在「机库与实装」选择机体和 AUX 功能槽，按「泵房回收」标记和编号选中实物，确认安装。[功能接口与战地维修臂](player-profile.md#功能接口与战地维修臂)

世界地图的「遗迹」图钉以当窗地点命名。雾桥泵站、铁杉泵站和高架泵站是同一活动的三个候选地点，同窗内所有玩家看到相同位置。服务器每 30 分钟开窗 20 分钟；关窗停止新队出发，已开始的探索按原时限继续。签名内测 1022 已在安卓模拟器与桌面好友间复验分工及个人撤离。

单人最多带 12 台、24 指挥点，好友合作每人最多 6 台、12 点，队伍最多 3 人。清除东西两处守卫后，带自己的机体靠近并校准对应阀门；可独自依次完成，也可分头处理。两阀就绪后只需一人开箱。每名指挥官带至少一台存活机体到出口确认个人撤离，先撤离者的结果会保留，队友可以继续。战斗时限 5 分钟。

出发每人支付 1 能源或使用已有救援凭证。按出发时的 UTC 日期，每名玩家当日首次实际胜利可获至多 2 份通用零件，实际入库量受仓容限制。再次参战仍记录各自机体经历。遗迹通关不计入锈轨扩地、钻头配方或快速回收的解锁进度。

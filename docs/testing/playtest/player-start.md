# 本机首次试玩入口

适用：最新可用1084 LAN包、既有1082默认模拟器／手机实际1083与R2六服。正式测试角色test_lead_fresh；更新2026-11-18。指定手机已安装1083，用户已自主进入私人基地，见[root实际观察签收](../../../openspec/changes/m23-usb-phone-lan-install/root-phone-install-result-review.md)；尚未组织完整真人试玩矩阵，不以此推断全部体验通过。

请主持人先准备同一台Windows电脑上的六服务和模拟器，核序列号/AVD后安装[1082原包](../../../build/private-beta/PunkLegion-beta-1082.apk)；安装帮助、音量与维护从[当前交付入口](../../current-playable-delivery.md)进入，实际组合以[稳定索引](../../../build/private-beta/current-playable.json)为准。不要安装诊断包。

最新可用[1084 LAN包](../../../build/private-beta/PunkLegion-beta-1084.apk)已[签收登记](../../../build/private-beta/operations/client-release-1084/ROOT-ACCEPTANCE.md)，尚未给手机安装。地址192.168.31.170，与下述1083相同局域网要求；安装前由主持人核包和设备。正常页面自动更新，不需要手动刷新／同步日程，真实连接异常按页面提示恢复。

1082地址10.0.2.2只服务同机模拟器；[1083 LAN包](../../../build/private-beta/PunkLegion-beta-1083.apk)使用192.168.31.170，已安装到指定手机，需与该电脑处于可达的同一局域网并保持六服运行。不要把两个端点包混用；宿主IP变化须重新评估。

打开游戏后按账号页提示注册本次新账号或登录本轮已有账号，进入私人基地。旧环境账号不导入R2。请勿使用其他应用的常用密码，也不要把密码、token或恢复信息写进反馈。连接或注册异常时告诉主持人，保留当前错误，不反复安装或注册。

接下来按自己的理解体验；可以提问、暂停或结束，没有必须完成的进度。私人基地左上「基地菜单」→「音效」可选择静音、低、中、高；试车台底部也可调同一设置。找不到返回或退出操作时可直接告诉主持人。

结束后欢迎说说原本想做什么、哪里困惑、哪些内容愿意继续体验。没有标准答案；主持人会提前说明是否记时或截图。手机UDP实战尚未重验，实体性能及声音听感由负责人终验，未执行。性能及其他范围详见[已知限制](known-limitations.md)。

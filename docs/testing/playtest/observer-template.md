# 首次试玩观察记录

状态：空白模板，尚无真人观察结果。维护角色：test_lead。更新：2026-11-13。适用：1077客户端＋原1076-delivery-r2后端的本机模拟器有限试玩；观察员使用，不在试玩前作为操作教程给玩家。性能脚本、AI操作或已有攻略熟练操作者不能冒充首次玩家观察。

主持人计划预留15–30分钟，参与者可以随时提前自愿停止，不要求凑满时长。开始前按[安卓试玩说明](../../android-private-beta.md#1077-本地内测)准备正式包和既有连接；结束保存记录后，按[资源收尾规则](../../../AGENTS.md#本机测试资源与收尾)关闭本次专用模拟器、ADB和辅助进程，保留当前试玩六服与共享服务，不清玩家库。安装和收尾操作由主持人处理，不塞入给玩家的说明。

开始前征得参与者对记时/笔记/截图的同意，说明可以随时停止。只协助准备环境和注册登录；不预先解释基地建筑、装配选择、路线、机关或获胜步骤。安全、连接或程序故障可以直接协助，记录发生了什么。
